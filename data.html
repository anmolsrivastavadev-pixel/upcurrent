Use Upcurrent's data in your own projects

Every 30 minutes Upcurrent checks GitHub, Hugging Face, arXiv, Hacker News, AI lab blogs, model providers and more, then works out what is rising. The results are plain JSON files. Use them in a bot, a newsletter, a research project or an app, for free. The only ask is a credit with a link back.

The feeds

  • data/api/today.jsonEverything on the dashboard right now: rising items, breakouts, hype check, receipts, top repos, trending models, free models, headlines and discussions.
  • data/api/history.jsonThe long memory: every item Upcurrent has tracked, when it was first spotted and what it was at, milestones it passed since, every breakout, and every free model added or removed.
  • data/api/daily/YYYY-MM-DD.jsonA frozen copy of today.json for each day (UTC), starting 2026-10-02. Good for comparing days.
  • data/latest.jsonThe raw file the site itself reads, including every source's original response. Bigger and less tidy; use it if you want to do your own scoring.

Full addresses start with https://anmolsrivastavadev-pixel.github.io/upcurrent/. No key, no sign-up, and browsers can fetch them directly from any website.

Try it

const res = await fetch("https://anmolsrivastavadev-pixel.github.io/upcurrent/data/api/today.json");
const data = await res.json();
for (const item of data.rising.slice(0, 5)) console.log(item.title, item.url);

What's inside today.json

FieldWhat it holds
aboutName, license, the credit line to use, and when the data was last updated.
pulseHeadline numbers for the day, like stars gained by tracked AI repos.
risingThe ranked movers across all sources, with a momentum score.
breakoutsThings named on 3 or more different sources in the last 3 days.
hypeHow much each item is talked about compared with how much it is actually used, with a plain verdict.
receiptsItems Upcurrent tracked before they passed a big milestone, and by how many hours.
github, modelsFastest-rising AI repos and Hugging Face models.
free, freeChangesAI models you can call at zero cost right now, and which ones were added or removed in the last 24 hours.
headlines, discussionsRecent AI news and the busiest threads.

The one rule: credit Upcurrent

The data Upcurrent creates (scores, breakouts, hype verdicts, receipts, free model changes) is licensed under CC BY 4.0. Wherever you show it, add this line:

Data from <a href="https://anmolsrivastavadev-pixel.github.io/upcurrent/">Upcurrent</a>
  • Commercial use is fine.
  • Titles, descriptions and links inside the data belong to their original publishers. Link to them rather than republishing whole articles.
  • Numbers are real and come from each source's official API. If a source was down, it is listed in data/latest.json under stale.
  • Please don't fetch more than once every few minutes. The data only changes every 30 minutes.
