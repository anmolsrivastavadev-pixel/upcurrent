# Ten design previews (27 Nov 2026)

Each file is a theme layer on top of the `redesign-option-2` page: fonts, tokens, and layout overrides.
To preview one locally, add `<link rel="stylesheet" href="design-previews/NN-name.css">` just before `</head>` in
index.html and serve the folder. The chosen one gets turned into a proper branch (dark mode, SEO pages, checks).
